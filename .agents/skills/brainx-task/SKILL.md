Follow `AGENTS.md` as the source of project rules.

1. Read `AGENTS.md`, `CLAUDE.md`, `docs/PROGRESS.md`, and the named task in `docs/TASKS.md`.
2. Read the linked detailed specification when it exists. Check the repository with read-only commands and report any mismatch with progress.
3. Confirm prerequisites from real evidence.
4. Explain the task in the owner's requested language: purpose, files, packages, project connection, expected result, and verification.
5. Ask exactly: “Should I implement this task now?” Stop without editing, installing, training, committing, or starting a server.
