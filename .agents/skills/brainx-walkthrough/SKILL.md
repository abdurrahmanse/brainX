Follow `AGENTS.md`. Read the task, its changed files, and real verification evidence.

- Use `git status --short`, `git diff --stat`, and focused diffs as evidence.
- Give a reading order: configuration first, main code next, tests last.
- Include short self-check questions, exact existing commands the owner can run, one safe reversible exercise, and answers after the questions.
- Do not edit files or start the next task.
